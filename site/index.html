DroneLog Devkit v1.1

Reproducible baselines for DroneLog v1.1: platform identification, payload state, payload mass and pickup/drop detection.

PX4 ULog pyulog grouped CV metadata controls

Runnable Devkit

The scripts read the DroneLog v1.1 release (log/ and metadata/). One command regenerates every result table of the revised paper:

venv/bin/python run_all.py --data <dataset_root> --out outputs

or task by task:

venv/bin/python scripts/task1_frame_classification.py   --data <dataset_root> --out outputs
venv/bin/python scripts/task2_payload_classification.py --data <dataset_root> --out outputs
venv/bin/python scripts/task3_mass_regression.py        --data <dataset_root> --out outputs
venv/bin/python scripts/task5_event_detection.py        --data <dataset_root> --out outputs

Benchmark Tasks

Task 1: Platform identification

Identify which of five vehicles flew from IMU-window features. Random Forest accuracy (5 s): 0.959.

Task 2: Payload state and scenario

Loaded or unloaded per window (RF 0.966); scenario per flight (RF 0.856).

Task 3: Mass estimation

Carried mass per platform, with per-mass errors and held-out masses.

Task 4: Navigation (v1.0)

Kept from v1.0 for reference; not part of the revised paper.

Task 5: Event detection

Pickup/drop detection from the cruise-phase motor command, 2 s tolerance.

Limitations

Each frame size is a single vehicle, so Task 1 identifies the platform; it cannot separate frame geometry from controller, IMU and firmware.
Pickup and drop times are manual labels (seconds after arming) with about ±1 s uncertainty.
Task 4 uses onboard GPS-level truth, which the PX4 EKF also fuses; it is kept from v1.0 for reference only.
