DroneLog

A real-flight PX4 telemetry dataset for UAV payload transition analysis and platform identification — with annotated mid-flight payload pickup and drop events and reproducible baselines.

📦 Dataset (Zenodo) 💻 Devkit (GitHub) 📄 Paper

Overview

DroneLog (version 1.1) contains 120 real PX4 flight logs (5 h 55 min). Its main part is 105 payload logs from two quadrotors (Holybro X500 V2 and X650) whose payload changes during flight: five scenarios, several carried masses and three trials per condition, flown by two pilots, with the pickup and drop times annotated. A smaller subset of 15 logs from five vehicles (250 mm–680 mm) supports platform identification. All data is released as native PX4 ULog files and pre-extracted CSV files.

  • 105 payload logs: X500 V2 (0.5 / 0.75 / 1 kg) and X650 (0.5 / 1 / 1.5 / 2 kg), 5 scenarios, 3 trials each
  • 84 annotated pickup and drop times (seconds after arming, about ±1 s)
  • 15 frame-size logs from 5 vehicles (250 / 450 / 500 / 650 / 680 mm) for platform identification
  • Full PX4 telemetry per flight: IMU, GNSS, attitude, local position, battery, motor commands
  • Machine-readable metadata (flights.csv, events.csv); native ULog and pre-extracted CSV files

Benchmark Tasks

The devkit reproduces every result table of the revised paper with one command (python run_all.py --data <dataset_root>):

1 · Platform Identification

Identify which of the five vehicles flew, from windowed IMU statistics, with metadata-only and 200 Hz controls.

2 · Payload State and Scenario

Is a payload attached in this window? Which of the five scenarios was this flight?

3 · Payload-Mass Estimation

Estimate the carried mass per platform, including masses held out from training.

4 · Navigation / Odometry (v1.0 only)

IMU-only strapdown integration scored against GPS and EKF tracks. Kept from v1.0; not part of the revised paper.

5 · Pickup/Drop Event Detection

Detect payload pickups and drops from the commanded thrust, scored with a 2 s tolerance.

Dataset Layout

dataset_root/
  log/
    frame_size/
      250mm/ d250_1.ulg  d250_2.ulg  d250_3.ulg
      450mm/ ...   500mm/ ...   650mm/ ...   680mm/ ...
    payload/
      x500v2/
        0.5kg/ 1_scenario_t1.ulg ... 5_scenario_t3.ulg
        0.75kg/ ...   1kg/ ...
      x650/
        0.5kg/ ...   1kg/ ...   1.5kg/ ...   2kg/ ...

  metadata/
    flights.csv   one row per log
    events.csv    pickup and drop times

Getting Started

Install the devkit and run any baseline directly from the command line:

source venv/bin/activate
pip install -r requirements.txt

python run_all.py --data <dataset_root> --out outputs

Each task can also be run on its own from scripts/. See the repository README for full usage details.
